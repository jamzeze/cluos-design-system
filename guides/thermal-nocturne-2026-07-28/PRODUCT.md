# Product

## Register

brand

## Users

The primary users of this visual system are CluOS product designers, engineers,
operators, and AI agents that create or maintain CluOS websites and applications.
The resulting interfaces serve professionals who need to understand system state,
coordinate work, and act with confidence without decoding technical noise.

## Product Purpose

Create an experimental visual identity for CluOS that can be evaluated before it
replaces any canonical production system. The identity must translate across brand
sites, operational products, dashboards, command centers, documentation, and AI
orchestration experiences while preserving clear action hierarchy.

Success means the system is recognizably CluOS without relying on generic AI
purple, neon sci-fi decoration, or copied Azigos layouts. It uses the official
Azigos palette as its primary color foundation and preserves selected CluOS colors
as functional nuance and semantic feedback.

## Brand Personality

Nocturnal, orchestral, precise.

The physical reference is an obsidian instrument panel crossed by bioluminescent
anatomical flows and machined copper signals: calm at rest, expressive only when
the system is doing meaningful work.

## Anti-references

- Generic dark AI dashboard with purple or cyan glow.
- Crypto, gaming HUD, cyberpunk, or spaceship-control aesthetics.
- Decorative glassmorphism, floating blobs, particle noise, and perpetual motion.
- Medical or clinical styling copied from Azigos; the relationship is chromatic,
  not a transfer of brand personality or composition.
- Template SaaS layouts built from repeated cards, hero metrics, gradient text,
  pills, or tiny uppercase labels above every section.
- Effects that hide content, compete with the main action, or communicate state by
  color alone.

## Design Principles

1. **Darkness creates focus, not spectacle.** Nocturnal surfaces reduce noise and
   make active context visible without becoming theatrical by default.
2. **Motion is evidence.** Every effect corresponds to focus, progress, state,
   hierarchy, or a real relationship in the system.
3. **Color has governance.** Azigos navy and lime establish identity; copper,
   oxblood, and teal clarify nuance and state.
4. **Complexity is earned.** Native CSS and SVG come first; GPU and 3D are used
   only when the visual meaning requires them.
5. **Products remain actionable.** Even in expressive brand moments, the current
   state, next action, ownership, and recovery path remain obvious.

## Accessibility & Inclusion

- WCAG 2.2 AA is the baseline for text, controls, focus, and interaction states.
- All state colors include labels, icons, shape, or text; color is never the sole
  signal.
- `prefers-reduced-motion` replaces spatial motion with static or crossfade states.
- The system supports keyboard navigation, visible focus, 44px minimum targets,
  zoom, dynamic text sizing, and high-contrast fallbacks.
- GPU effects must have a static fallback and must not block content or input.
