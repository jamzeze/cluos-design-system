Tecnologia

A decisão de runtime segue a menor camada capaz. A identidade não exige uma biblioteca específica; complexidade só entra quando gera compreensão real.

Core / default baixo custo

CSS · SVG · WAAPI

Estados, transições, microinterações, malhas e diagramas leves.

  • Primeira escolha para produto
  • Fallback estático natural
  • Motion para sequências UI/SVG complexas
Specialist / approved uso governado

Rive · dotLottie · PixiJS

Vetores interativos, animações portáteis e cenas 2D densas.

  • Rive para interação com estados
  • dotLottie para narrativa vetorial
  • PixiJS quando DOM/SVG não escala
Conditional / exceptional gate técnico

Paper Shaders · Three.js · R3F

Shaders aprovados e 3D quando profundidade é parte da informação.

  • Pin de versão obrigatório
  • Um canvas GPU por viewport
  • Spline/GSAP apenas em narrativa cinematográfica

Acessibilidade

WCAG 2.2 AA, foco visível, alvos mínimos de 44px, movimento reduzido e conteúdo íntegro sem JavaScript são parte do contrato.

12.63:1Deep Navy sobre Tech Lime

Contrato WCAG 2.2 AA

  • Estados combinam cor com texto, forma, valor ou tabela.
  • Todo controle tem foco visível e alvo mínimo de 44 × 44px.
  • Movimento respeita a preferência do sistema e o controle local.
  • Conteúdo, hierarquia e próximas ações permanecem íntegros sem JavaScript.
  • SVGs informacionais recebem título e descrição; decorativos ficam ocultos.
  • Nuances térmicas nunca são o único canal para risco ou sucesso.
